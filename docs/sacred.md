# The sacred and the shared, in all four tongues

Made from `assets/lang/sacred.ron` by `cargo run --release --bin lang -- sacred` (a test checks this file is up to date). Don't edit it by hand.

Each name is followed by how to say it, the loud syllable in capitals. The English name is the one the game shows first.

## The gods

The Roduro names are canon (`pantheon.md`). The gods are older than the split of the tongues, so the other three names are the same old name worn down each tongue's way.

## How the tongues put words together

| | Roduro | Qotiro | Horaro | Ṭaḍoro |
|---|---|---|---|---|
| Order in a compound | describing word first | describing word first | main word first | main word first |
| A people | -ro | -roq | roi- | shei- |
| One who does it | -qe | -ak | he- | he- |
| Where it is | -la | -ar | la- | ya- |
| A little one | -li | -ik | li- | yi- |
| A great one | -ra | -rek | ra- | sha- |
| The highest | hi- | xi- | hi- | hi- |
| "of" | yi | di | i | yi |
| Stress | next to last | first syllable | next to last | last syllable |
| A man's name ends in | o, u | k, t, q, x | u, o | th, h, s |
| A woman's name ends in | a, i | n, r, m | a, ia | ai, a, i |
| Either | e, ì | d, g | i, e | e, u, sh |
