# Glossary: the First Speech roots in all four tongues

Made from `assets/lang/` by `cargo run --release --bin lang -- glossary` (a test checks this file is up to date). Don't edit it by hand: change the roots or the sound rules.

- **canon**: the Roduro word already existed, and the root was worked backwards from it.
- *italic*: an exception to the sound rules (`irregular.ron`).
- a word marked ‹R›, ‹Q› or ‹H›: borrowed from that tongue (`loans.ron`).
